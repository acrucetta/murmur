# Verification Checklist

Use this before handoff.

## TDD Evidence
- [ ] Failing tests added first (`red`).
- [ ] Minimal implementation to pass (`green`).
- [ ] Refactor pass completed (if needed).

## Command Log
- [ ] List each command run.
- [ ] Mark pass/fail outcome.
- [ ] Include key failure cause if fixed during the task.

## Quality Gates
- [ ] Acceptance criteria validated.
- [ ] Regressions checked for touched modules.
- [ ] Error messages/log output remain actionable.
- [ ] No architectural boundary violations introduced.

## Handoff Notes
- [ ] Residual risks documented.
- [ ] Assumptions documented.
- [ ] Next logical steps documented.
